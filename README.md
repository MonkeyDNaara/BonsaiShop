# Bonsai Shop

Our first full multi-page website, built together with Elias. The concept: a subscription shop where buying/sponsoring a bonsai tree also funds rainforest conservation — "klein im Namen, groß in der Wirkung" (small in name, big in impact).

## Pages

| Page | Purpose |
|---|---|
| `index.html` | Landing page — the pitch, the "why rainforests matter" section |
| `products.html` | Product listing (still a stub, layout not filled in yet) |
| `templates.html` | Subscription plan templates |
| `price.html` | Pricing |
| `reviews.html` | Customer reviews |
| `login.html` | Login page (front-end only, no real auth) |

Shared header with a dropdown/hamburger menu and a consistent footer across every page.

## Stack

Plain HTML5 + CSS3. No JS, no framework, no build tools — this one was about practicing semantic HTML and getting a multi-page site to feel consistent without repeating ourselves too much in the CSS.

## Status

Not all pages are finished — `products.html` in particular is currently just the shared header/footer with nothing in between. This was a scoped class project rather than something we're actively continuing, so I'm leaving it as-is as a snapshot of that stage of learning rather than polishing it further.

## Running it

Open `index.html` directly in a browser, or serve the folder with any static file server (e.g. VS Code Live Server).
